# Keyboard shortcuts

[← Back to the README](../README.md)

On Windows, use **Ctrl** wherever **⌘** appears.

These are global — they work while another app has focus, which is the point. You never have to
click Phoenix during a call.

## Answering

| Shortcut | Action |
|---|---|
| `⌘ ↵` | Answer the last thing the interviewer said |
| `⌘ ⇧ ↵` | Screenshot the screen **and** answer what is on it |
| `⌘ ⌥ ↵` | Queue a screenshot without answering |
| `⌘ ⇧ Space` | Open chat and type a question |
| `⌘ H` | Take a screenshot |

## Reading the answer

| Shortcut | Action |
|---|---|
| `⌘ ←` | Previous answer |
| `⌘ →` | Next answer |
| `⌘ ↑` | Scroll the answer up |
| `⌘ ↓` | Scroll the answer down |

## The window

| Shortcut | Action |
|---|---|
| `⌘ B` | Show or hide the overlay |
| `⌘ T` | Click-through on/off — the mouse passes through to what is behind |
| `⌘ ⇧ ←` `→` `↑` `↓` | Move the overlay |
| `⌘ ⌥ C` | Centre the overlay |

`⌘ ⌥` with the arrow keys also moves the window, kept from an earlier version.

## Clearing

| Shortcut | Action |
|---|---|
| `⌘ ⌫` | Clear the answers |
| `⌘ ⇧ ⌫` | Clear the transcript |
| `⌘ ⌥ ⌫` | **Full privacy reset** — clears everything and stops capture |

`⌘ ⌥ ⌫` is the one to remember if something unexpected happens mid-call. It stops listening and
leaves nothing on screen.
